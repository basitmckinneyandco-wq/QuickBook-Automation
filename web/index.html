Where the policies come from

The dashboard reads its rows from a published Google Sheet link. Paste a new one here if the link ever changes — it is tried before it is kept, so a wrong link cannot leave you with an empty dashboard.

Company file

Pick the company this dashboard should work in. QuickBooks serves one company at a time, so while it is running you can only switch to the one it has open — with QuickBooks closed, any of these can be started.

Each company keeps its own history file, so what was created in one is never mistaken for work already done in another.

Turn on real writes

  1. Open your company file in QuickBooks Desktop.
  2. Run python -m qb_agent whoami to print its full path.
  3. In config.json set "mode": "quickbooks", "allow_writes": true, and paste the path into company.file_path.
  4. Restart the app — the badge turns red and reads LIVE.

Before you send invoices

Your invoices point at accounts, templates and items by name. If one is renamed in QuickBooks, every invoice of that kind fails. This checks them all at once.
